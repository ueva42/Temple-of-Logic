Klassen-Fortschritt & Voting

Du gibst für eine Klasse mehrere Klassenbelohnungen frei. Die Klasse stimmt in der Schüleransicht ab, welche Belohnung sie möchte. Während die Klasse arbeitet, werden XP gesammelt; bei Erreichen der Ziel-XP ist die gewählte Belohnung freigeschaltet.

Aktuelle Voting-Runde

–

Neue Voting-Runde starten

Beim Start wird eine neue Runde für die gewählte Klasse angelegt. Alte Runden derselben Klasse werden automatisch geschlossen.

Belohnungen in diese Runde aufnehmen

Wähle hier aus deinen angelegten Klassenbelohnungen (Kino, Frühstück, Spiele-Stunde …), welche in der aktuellen Voting-Runde zur Auswahl stehen sollen.

Neue Klassenbelohnung anlegen

Beispiele: Kino-Nachmittag, Spiele-Stunde, Unterricht draußen, Klassenfrühstück … Diese Belohnungen kannst du anschließend in Voting-Runden verwenden.
